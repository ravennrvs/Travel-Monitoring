# Travel-Monitoring
Platform pemesanan dan monitoring tiket pesawat untuk pengguna, member frequent traveller, dan manajer travel.

# SkyTravel: Platform Pemesanan & Monitoring Tiket Pesawat
SkyTravel membantu pengguna mencari, memesan, dan memantau tiket pesawat dalam satu
tempat. Sistem membedakan tiga peran, masing-masing dengan fitur sendiri.

## Fungsi Utama:

**- Pengguna**
- Mencari jadwal, maskapai, dan harga tiket untuk satu atau beberapa tujuan
- Memesan, membayar, dan membatalkan tiket
- Melihat tiket yang telah dipesan

**- Member Frequent Traveller**
- Seluruh fitur Pengguna
- Mencari penerbangan multi-destinasi dan membandingkan harga serta jumlah penerbangan
- Membandingkan penerbangan berdasarkan tujuan, tanggal, dan jam keberangkatan
- Melengkapi data profil dan memvalidasi tiket

**- Manajer Travel**
- Memantau seluruh status booking dan memfilternya
- Memesan tiket atas nama pengunjung
- Mengotorisasi tiket menggunakan kode booking reference

## Alur Status Booking:
Menunggu pembayaran → Dibayar (Booked) → Diotorisasi (Confirmed)
Pesanan yang dibatalkan berstatus Cancelled.
